# Style enforcement loop

`.ai-style-rules.md` (maintained by the `inherit-legacy-style` skill) captures this repo's own implicit conventions, and `copilot-review-instructions` regenerates `.github/instructions/*.instructions.md` (path-scoped Copilot PR-review directives) from it, the repo's instruction files and docs, and the prohibitions `inherit-legacy-style` states about `.ai-style-rules.md`, along with the `# Code reviews` section of `.github/copilot-instructions.md`, which points Copilot's reviewer at those files and names what CI already blocks. Neither skill stamps a marker into what it writes or treats any file as its own: not every contributor has these skills, so any of these files may be edited directly. `copilot-review-instructions` therefore updates each file in place, keeps any directive no current source backs unless a person confirms it stale, and never deletes a file unconfirmed. In `.github/copilot-instructions.md` it edits only the `# Code reviews` section, bounded by that heading and the next H1. Everything outside the section is guidance that also steers Copilot's cloud agent, which is why the nightly workflow below cannot write this file at all: its allowlist covers only the path-scoped files and `.ai-style-rules.md`.

A nightly workflow (`.github/workflows/nightly-style-refresh.yml`) re-runs this loop unattended against `main` and merges the result through a Copilot-reviewed PR, so `.ai-style-rules.md` and the generated instruction files can change without a human commit. Its diff allowlist deliberately excludes `.github/copilot-instructions.md`. Every file it does admit carries `excludeAgent: "cloud-agent"`, so nothing an unattended session writes can reach Copilot's cloud agent; that file carries no such exclusion, and no diff check on it would help, since the risk is what gets written inside the `# Code reviews` section rather than outside it. The section is therefore refreshed only on a human-run invocation of the skill, and its list of path-scoped files can lag a nightly run that adds or drops a bucket.
